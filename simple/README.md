# Дозор — минимальная версия

На каждой машине есть только `run.py`, `device.json`, `field.json` и `mqtt.py`.

* компьютер: `python run.py` — MQTT-брокер (если нужен), веб-панель и диспетчер;
* дрон: `python run.py` — MQTT-агент и адаптер к установленному ROS/sverk стеку;
* ровер: `python run.py` — MQTT-агент и адаптер к своему управлению.

`field.json` меняется только на компьютере. Команда `python sync.py` передаёт его
на дрон и ровер. Старый ROS-workspace сохранён рядом и не используется этой версией.
